# Заметки для участников

English version: [CONTRIBUTING.en.md](CONTRIBUTING.en.md)

В репозитории должны лежать только открытые сценарии-обертки, тесты и документация проекта `wac-client-windows-setup`.

Не добавляйте в публичный репозиторий бинарники Microsoft Windows Admin Center, распакованные файлы WAC, `innoextract.exe`, локальные журналы, временные загрузки, машинно-специфичные диагностические данные, персональные пути, секреты и рабочие заметки агентов.

Перед публикацией релиза запустите из корня репозитория:

```powershell
.\scripts\test-release.ps1
.\scripts\build-dist.ps1
```

Обязательные проверки релиза:

- `.coderabbit.yaml`, `AGENTS.md`, `CONTRIBUTING.md`, `CONTRIBUTING.en.md`, `install-wac.cmd`, `interactive-installer.ps1`, `wac-setup-engine.ps1`, `tui\*.ps1`, `README.md`, `README.en.md`, `VERSION`, `SECURITY.md`, `SECURITY.en.md`, `LICENSE`, `NOTICE.md` и `NOTICE.en.md` присутствуют.
- В репозитории и релизном zip нет официального установщика Microsoft WAC, распакованных файлов WAC, MSI/MSIX/AppX/CAB и `innoextract.exe`.
- В публичных файлах не осталось старых имен пакетов с привязкой к версии и старых названий offline-installer.
- В публичных файлах не осталось путей рабочей станции разработчика, путей профиля пользователя, примеров из папки загрузок и машинно-специфичных диагностических данных.
- Pester-тесты проходят.
- PowerShell-файлы разбираются Windows PowerShell без синтаксических ошибок.
- PSScriptAnalyzer не сообщает диагностик уровня `Error`, если модуль установлен.
- Архив релиза собирается в `dist\wac-client-windows-setup.zip`, рядом создается файл `.sha256`.

## Версионирование

Проект использует SemVer в файле `VERSION` без префикса `v`; git-теги релизов используют тот же номер с префиксом `v`, например `v0.1.0`.

- `PATCH`: исправления наших скриптов, документации, CI и процесса выпуска без изменения пользовательского контракта.
- `MINOR`: поддержка новой версии Windows Admin Center или новые обратно совместимые возможности установщика.
- `MAJOR`: несовместимые изменения CLI, структуры пакета, установочной логики или крупный рефакторинг, требующий внимательной миграции.
